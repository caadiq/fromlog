# 공개 웹 변경 사항의 Flutter 앱 반영

- 작업일: 2026-09-27
- 기준: 모바일 공개 웹의 검색 C안 및 검증 9·14·15번까지의 변경과 앱 `46193c8e` 비교.
- 범위: 홈, 공통 헤더, 멤버, 앨범·곡·응원법, 사진·티저, 영상, 일정·검색·상세.
- 관리자 화면은 기존대로 모바일 웹을 사용한다. 앱에 관리자 화면을 새로 만들지 않는다.

## 반영한 차이

| 화면 | 앱에 반영한 내용 |
| --- | --- |
| 검색 | 큰 날짜와 세로 구분선의 C안. 오른쪽은 분류/출처와 제목, 배경 날짜 상자 제거. 월만 정해진 일정은 날짜 미정 표시. |
| 검색 탐색 | 결과에서 Back → 빈 검색/최근 검색 → 일정 화면. 입력을 다시 편집하다 Back을 누르면 기존 결과 복원. 상세 왕복 시 결과/위치 유지. |
| 검색 필터·로딩 | 일정과 같은 분류 선택 상태. 필터 결과가 짧아 스크롤할 수 없어도 다음 페이지 조회. 실패 시 자동 재호출 중지, 기존 결과를 유지하며 명시적 재시도 제공. |
| 공통 헤더 | fromlog 워드마크와 홈 이동, SNS 버튼 터치 영역 확대. 기존 X 링크는 이미 올바른 주소였다. |
| 홈 | 한 API 실패가 다른 섹션을 가리지 않도록 분리. 실패 섹션만 재시도. 실제 0과 조회 실패 구분. 멤버 카드에서 선택 멤버 상세로 이동. |
| 멤버·앨범·곡 | 실패/빈 결과/404 구분과 재시도. 상세 경로 인자가 바뀌면 새 데이터 조회. 이미지 실패 시 공간을 유지하는 대체 표시. |
| 사진 목록 | 멤버·앨범의 2열 사진을 화면 근처에서만 생성. 필터와 원본 순서 유지, 화면 폭에 따라 높이 재계산. 미리보기 주소 누락 시 사용 가능한 주소로 대체. |
| 사진·티저 뷰어 | 상하단 도구와 사진/영상 컨트롤의 영역 분리. 긴 정보 시트 스크롤, 이미지 실패 재시도, 다운로드 시작 실패 안내와 중복 시작 차단. 동작 줄이기 설정 반영. |
| 티저 영상 | 현재 슬라이드의 플레이어만 생성하고 이탈하면 해제. 초기화 제한 시간 20초와 실패 후 재시도. |
| 곡·응원법 | 별도 MV가 없어도 응원법이 있으면 진입 버튼 표시. 곡 조회 실패 재시도, 경로 변경 시 이전 재생/가사 상태 제거. |
| YouTube | 로딩 실패 시 재시도 버튼. 정상 재생과 앞서 수정한 전체화면 복구 경로는 유지. |
| 달력 | 월 전환에 동작 줄이기 설정 반영. 년월 바로 옆의 오른쪽 화살표는 직전 +138에서 수정. |

## 이미 적용되어 있거나 네이티브 동작을 유지한 부분

- 영상 채널/쇼츠 필터, 추가 로딩 오류 복구, 일정 분류 순서·날짜 상태·상세 오류 복구, 공지와 긴 본문 처리는 기존 앱 구현을 유지한다.
- 홈 전체보기의 탭 이동, 검색 최근 기록과 검색어 채우기, 곡의 YouTube 열기, Kakao 외부 지도 버튼은 사용자가 정한 앱 동작이다.
- 사진 저장은 Android 다운로드 서비스를 사용한다. 파일 확장자 판별은 이미 있으며, 뷰어를 닫아도 시스템 다운로드는 계속된다. 웹의 브라우저 fetch 취소 동작으로 대체하지 않는다.
- 원본 URL이 제공되는 사진은 원본을 우선 사용한다. 멤버 사진 API가 원본 URL을 제공하지 않는 경우에는 제공된 미리보기 주소를 사용한다. 서버 API나 저장소는 변경하지 않았다.
- 앱 일반 화면은 세로 고정이며 YouTube 전체화면만 회전한다. 가로 웹 전용 배치를 앱에 추가하지 않는다.

## 자동 검증

- 전체 Flutter 테스트 **125개 통과**. 정적 분석 error/warning 없음, 기존 info 10개.
- 검색 및 년월 헤더: 폭 320·390·800에서 배치 예외 없음, 월만 확정된 일정 표시와 화살표 간격 확인.
- 분류로 첫 페이지가 모두 숨겨진 경우 다음 페이지 로드, 검색 실패 후 수동 재시도, 상세 → 검색 → 빈 검색 → 일정 순서 검증.
- 앨범 500 응답 → 재시도 성공 → 404 구분, 홈 일부 실패 시 다른 섹션 유지 및 해당 API만 재시도.
- 600장 갤러리에서 초기/끝 위치 모두 생성된 항목 40개 미만, 화면 폭 변경 뒤 마지막 사진 도달.
- 모의 네이티브 영상 플랫폼으로 현재 티저만 생성/재생, 옆 슬라이드 이동 시 이전 플레이어 해제, 실패 후 새 플레이어로 재시도 확인. 실제 디코더 성능 시험과 구분한다.
- 테스트: `app/test/app_public_parity_test.dart`, `teaser_parity_test.dart`, 기존 탐색·검색·전체화면 회귀 검사.
- 로그: `/tmp/fromlog-parity-finaltests.log`, `/tmp/fromlog-parity-finalanalyze.log`.
- 캡처: `/tmp/fromlog-app-parity/search-parity-{320,390,800}.png`, `month-header-{320,390,800}.png`.

## 배포 및 Android 확인

- **Otto 2.0.0+139 / Android versionCode 2139 발행 완료**. arm64 릴리스 빌드·업로드 및 2138 기준 업데이트 API의 2139 응답 확인. 선택 업데이트이며 새 서버 API를 요구하지 않는다.
- Waydroid Android 13에서 ARM64 릴리스를 설치하고 실제 데이터의 홈, 년월 화살표 배치, `fromis` 검색 C안, YouTube 상세 → 검색 결과 복귀 → 빈 검색/최근 기록으로 돌아가기와 키보드 표시를 직접 확인했다. 최종 발행 릴리스 2139도 설치하여 버전을 확인했다.
- 실제 Android 캡처: `/tmp/fromlog-app-parity/android-schedule.png`, `android-search.png`, `android-detail.png`, `android-search-return.png`, `android-search-empty.png`. 테스트 데이터로 운영 일정을 수정하거나 실제 알림을 전송하지 않았다.
- 웹 운영 배포·git push 없음. 변경/검증 내용을 커밋으로 기록한다.
- 자동 배치 검사는 모든 실제 폰의 글자 크기·시스템 제스처·장시간 스크롤 성능을 보장하지 않는다. YouTube 전체화면 진입의 짧은 멈춤은 기존 10번 문서의 한계를 유지한다.
