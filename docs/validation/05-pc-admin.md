# 05. PC 관리자

- 상태: 완료
- 검증일: 2026-09-26
- 기준 버전: `d73e0a76` 이후 이번 변경
- 대상: PC 관리자 전체 라우트의 목록·편집 화면, 공통 다이얼로그·선택기, 주요 저장/실패 흐름
- 환경: 개발 웹 + Chromium headless. 일반 1440×900, 경계 1100×600, 낮은 화면 1440×450 및 팝업 1440×350. 추가로 1099px 분기, CSS 125% 확대, 동작 줄이기 설정 확인.
- 데이터: 초기 화면 점검에는 공개 조회 스냅샷을 사용했고, 저장한 회귀 검사는 합성 데이터만 사용한다. 모든 `/api/` 요청을 브라우저에서 대역 처리하고 외부 호스트 요청을 차단한다. 운영 DB 쓰기·실제 봇 실행·외부 API 사용량 소비 없음.

## 범위와 후속 확인

- 브라우저 UI와 요청 계약 검증이다. 실제 DB 저장/검색 반영·큐 실패 복구는 2~4번 기록을 함께 참고한다.
- 이미지 파일의 실제 업로드·변환·S3 저장, 인스타그램/지도/유튜브의 실서비스 응답, 복합 일정의 모든 입력 조합을 이번 브라우저 검사로 보장하지 않는다. 입력·외부 콘텐츠 검증은 7번에서 별도로 수행한다.
- 순서 변경의 서버 쓰기 잠금은 코드 경로를 확인했다. 모든 드래그 궤적·동시 탭 충돌을 자동 재현한 것은 아니다.
- CSS 확대는 실제 브라우저 줌/OS 글꼴 확대와 다르다. Firefox/Safari·실기기·저사양 장치 애니메이션은 미검증이다.
- 모바일 공유 확인창 회귀 확인은 모바일 전체 검증을 대신하지 않는다. 다음 단계는 **6번 모바일 관리자 일정**이다.
