## 발견 문제와 수정

1. **없는 멤버 사진 페이지가 계속 로딩**: 멤버 로딩/실패/없음/사진 조회를 분리했다.
2. **조회 실패를 빈 상태나 404처럼 표시**: 홈 각 섹션, 멤버·앨범·곡·응원법에 오류 안내와 재시도를 제공했다. 응원법은 곡 조회 완료를 기다리고 이전 곡의 임시 데이터를 제거했다.
3. **홈의 실제 0을 5명/대시로 표시, 멤버 카드가 목록으로 이동**: 실제 데이터와 로딩 상태를 구분하고 선택 멤버 상세로 연결했다.
4. **깨진 이미지 및 미리보기 주소 누락**: 이미지 영역을 보존하고 뷰어 URL에 medium → thumb → original 대체 경로를 추가했다.
5. **사진 저장이 무조건 WebP 이름·미리보기 파일, HTTP 오류도 저장 가능**: 원본 주소/확장자를 유지하며 응답·타임아웃·중복 클릭·취소·실패 안내를 처리한다. 15초 다운로드/20초 미디어 대기 제한을 적용했다.
6. **이전 티저의 재생이 슬라이드 밖에서 지속될 가능성**: 현재 슬라이드에만 video를 생성하여 이탈 시 제거한다.
7. **위치 표시 점을 Swiper가 덮어 클릭 불가**: 뷰어 하단에 독립 영역을 확보했다. 영상 컨트롤도 점과 겹치지 않는다.
8. **소개창이 즉시 나타나고 사라짐, 모달 포커스 누락**: 소개창의 배경/시트를 함께 전환하고 뷰어·정보창·소개창의 포커스/닫기/Back을 연결했다. 정보 시트는 핸들만 드래그하고 본문은 스크롤한다.
9. **긴 텍스트·회전 대응 미흡**: 최소 열 너비/줄바꿈/가상 사진 높이 재계산, 안전 영역 여백, 터치 버튼 이름·크기를 보완했다. 긴 소개창 제목은 닫기를 밀어내지 않는다.
10. **가로 응원법 영상이 화면 대부분을 차지**: 16:9 비율을 유지하며 높이를 40dvh까지 제한하여 가사 스크롤 공간을 남겼다. 플레이어 재시도 버튼과 별도 MV 없는 곡의 응원법 링크도 제공한다.
11. **상단 X 링크 주소가 없음**: 공통 상수는 `x`인데 두 헤더가 `twitter`를 읽고 있었다. PC/모바일 모두 `SOCIAL_LINKS.x`로 수정했다. 14번의 이전 SNS 점검에서 놓친 항목으로 추가 기록한다.

## 반영 상태와 한계

- 프론트는 **개발 사이트만 반영**, 운영 배포와 push는 하지 않았다. 공용 컴포넌트 변경은 같은 dev의 일정 포스터·PC 상태 안내에도 적용된다.
- 실제 사진 다운로드와 YouTube iframe 로딩은 확인했지만, 외부 영상 전체 재생/음원 정밀 싱크·접근 제한 영상·실제 다운로드 앱 UI는 검증하지 않았다.
- 화면 크기 변화/터치 이벤트를 자동화한 결과다. Android/iOS의 실제 주소창, 노치·시스템 제스처, 장시간 프레임, 멀티터치는 실기기 확인 범위다.
- 남은 전체 계획 항목은 **10·13번 Android 실기기 확인**과 기존 접근 제한 영상 2건의 후속 확인이다. 브라우저 검사 완료를 모든 기기의 무결함 보장으로 취급하지 않는다.
