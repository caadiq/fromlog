# 8. PC 공개 영상·일정 검증

- 상태: 완료 (아래 범위 및 한계 기준)
- 날짜: 2026-09-26
- 대상: 개발 사이트의 PC 공개 `/video`, `/video/:category`, `/schedule`, 검색, `/schedule/:id`
- 방식: 실제 라우트와 React 화면에 합성 읽기 API를 연결한 Chromium 테스트 + 실제 개발 데이터 읽기 전용 확인
- 변경 범위: PC 프론트엔드. DB·수집 봇·모바일 화면·앱·운영 웹 배포는 변경하지 않는다.

## 검증 범위

### 영상

- 메인·카테고리·쇼츠 목록, 외부 YouTube 주소/새 탭 속성, 긴 제목·채널명.
- 채널 선택, 새로고침, 뒤로가기, 키보드 방향키/End/Enter/Escape.
- 최초 조회 실패/재시도, 실제 빈 목록, 24→48개 추가 조회 및 중복 없음.
- 다음 페이지 실패 후 자동 요청이 멈추고 수동 재시도로 복구됨.
- 긴 툴팁의 화면 하단 위치와 스크롤 시 제거, 썸네일 전체 실패 대체 표시.

### 일정

- 선택 날짜·카테고리 필터, 상세 왕복 후 선택 유지.
- 검색 → 상세 → 뒤로가기 시 검색 결과 복원 → 다시 뒤로가기 시 빈 검색 화면.
- 월별 실패·재시도, 상세 500/404 구분, 빈 일정.
- 달력 전진·후진·연속 전환·연월 직접 선택·오늘 이동, 4/5/6주 달력, 화면 크기 변경.
- `prefers-reduced-motion: reduce`에서 달력 이동/잔여 이전 달 없음.
- 유튜브 일반/쇼츠/예정, X, 행사, 예능, 기타, 팬사인회, 티켓팅, 콘서트, 기본 상세 레이아웃.
- 포스터 확대·이미지 전환·Escape 닫기와 상세 경로 유지.
- 날짜 없음·월만 확정된 일정의 상세 표기.

### 스크롤 측정

합성 일정 35건과 긴 제목/채널명으로 확인했다. `scrollHeight - clientHeight` 값이다.

| 화면 | 전체 세로 넘침 | 일정 목록 세로 넘침 | 판정 |
| --- | ---: | ---: | --- |
| 1920×1080 | 0px | 3472~3473px | 목록 내부만 스크롤 |
| 1440×900 | 0px | 3652px | 목록 내부만 스크롤 |
| 1100×700 | 60px | 4292px | 달력 영역이 남은 높이를 넘으므로 전체 스크롤 허용 |
| 1280×600 | 225px | 3727px | 낮은 화면에서 전체/목록 스크롤 허용 |

6주 달력에서 낮은 화면 → 1920×1080으로 바꾸면 전체 넘침이 0px로 회복된다.
1280×400에서도 연월 선택기 하단을 내부 스크롤로 조작할 수 있다.
기존 달력/목록 높이 계산은 정상으로 확인되어 변경하지 않았다.

## 한계와 후속

- 합성 테스트는 외부 미디어 네트워크를 막고 레이아웃/링크/iframe 주소·권한을 검사한다. 실제 개발 사이트의 영상 썸네일 로드도 별도로 확인했다.
- 실제 재생은 위 표본 1건으로 확인했으며, 모든 계정/지역/연령 제한 및 전체 영상 가용성까지 통과했다는 의미는 아니다. 앞 단계의 접근 제한 영상 2건은 후속 항목으로 유지한다.
- Chromium의 PC 뷰포트 검증이며 실제 태블릿 Safari/앱 WebView 검증은 9·10번에서 수행한다.
- 기존 번들 크기 및 Browserslist 경고는 빌드를 막지 않았다. 번들 성능은 13번에서 검증한다.
- 모바일은 월 전환·가로 날짜 띠·달력 펼치기/접기 애니메이션을 9번에서 확인한다.
