# 모바일 관리자 최종 점검 — 2026-09-25

## 결과와 방법

개발 사이트의 모바일 관리자에서 21개 브라우저 시나리오 묶음과 프런트 빌드가 통과했다. 발견한 저장 중 닫기/뒤로가기 문제를 수정했다.

- Chromium + Playwright, 기본 390×844 및 320px 좁은 화면.
- 모든 테스트 API는 모의 응답으로 인터셉트. 실제 일정·영상·봇 변경, 봇 실행, Gemini 호출 및 운영 배포 없음.
- 정상 흐름 외에 실패/재시도, 빈 목록, 긴 제목, 중복 요청 차단, 뒤로가기, 새로고침, reduced-motion 확인.
- visualViewport 높이/오프셋으로 키보드를 시뮬레이션. 실제 Android/iOS 키보드, Google OAuth 로그인, 외부 Instagram/YouTube/X 실호출은 이번 검증에 포함하지 않았다.

## 수정 사항

1. 큐 등록 중 닫기/취소 버튼과 Escape/뒤로가기로 창을 닫을 수 있었다. 등록 중 버튼을 비활성화하고 ref 기반으로 닫기를 차단했다. 실패 후에는 다시 닫을 수 있다.
2. 공용 뒤로가기 훅은 저장 중 콜백이 닫기를 거부해도 history 항목을 소비했다. 콜백이 명시적으로 false를 반환하면 항목을 복구하도록 보완했다. 큐·일정 수정·영상 편집·고정 링크 편집·봇·삭제 확인에 적용했다.

지연된 큐 등록 중 뒤로가기 3회, Escape, 버튼 상태, 요청 1회만 발생, 실패 후 정상 닫기/재열기/뒤로가기 복구를 확인했다. 일정 삭제 중 뒤로가기도 확인했다.
