# PC 일정 관리자 목록 시안 — 2026-10-16

상태: 사용자가 A안을 선택하여 개발 사이트에 적용 완료. 운영 프론트는 미배포.

## 요청

현재 편집 버튼을 눌러야 수정/삭제가 나타나는 흐름을 개선한다. 기존 fromlog의 종이색 배경, 얇은 구분선, 굵은 날짜·시간과 달력 구조를 유지한다.

## 비교

- A (`option-a.html/png`): 시간 / 제목·분류·출처 / 상시 수정·삭제 아이콘. 조작 영역의 폭 고정.
- B (`option-b.html/png`): 테두리 카드. 상단 시간·분류, 중간 제목, 하단 출처·텍스트 작업 버튼. 행 높이가 가장 큼.
- C (`option-c.html/png`, 최초 제안 시 추천): 구분선 목록. 제목에 넓은 폭을 주고, 아래 줄에 분류·출처와 텍스트 수정·삭제 버튼을 분리.
- `comparison.html/png`: 오른쪽 목록 세 안 비교.

## 공통 동작 설계

- 별도 편집 모드 없음. 제목은 공개 상세, 수정/삭제는 독립된 버튼.
- 긴 제목은 최대 두 줄. 아이콘에는 접근 가능한 이름·툴팁·키보드 포커스 제공.
- X는 현행 기능과 동일하게 삭제만 제공. 자동 생일 등 수정 불가 항목은 실제 구현 시 작업 버튼을 제공하지 않음.
- 삭제는 확인 다이얼로그를 거치도록 구현. HTML 버튼은 동작 설명만 열며 API를 호출하지 않음.
- 예시 일정은 화면 구성용이며 정확한 일정 정보 확인이나 데이터 변경이 아님.

## 검토

Chrome headless에서 HTML 렌더링 및 비교/C 전체 화면 캡처를 확인했다. 카드형은 목록이 더 길어지는 차이가 있다. 실제 구현 시 기존 날짜 선택, 필터, 검색, 독립 스크롤과 상세 복귀 동작을 유지해야 한다.
