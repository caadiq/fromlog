# 전체 UI 리뉴얼 시안 (보류 중 — 기능 완성 후 진행)

2026-07-11 확정된 방향. 다른 페이지 디자인을 모두 정하고,
기능이 완성된 후에 일괄 적용하기로 함.

## 확정 사항
- **방향: C안 — 에디토리얼 매거진** (PC/모바일 공통)
  - 배경 #FBFBF9 · 잉크 #141613 · 헤어라인 #E8E8E3 · 그린 #548360 유지
  - 대형 워드마크 `fromis_9` (`_9`만 그린 아웃라인), 키커/넘버링 레터스페이싱
  - 카드 라운드 최소화(4px), 헤어라인 구분선, 통계 스트립
- **히어로 카피**: 키커 `SINCE 2018. 01. 24` + 공식 인사 멘트 인용
  "인사드리겠습니다. 둘, 셋! 안녕하세요, 프로미스나인입니다!"
- **PC 히어로 이미지**: 최신 앨범 세로형(height>width) 컨셉 포토 중
  랜덤 4~5장 → 5~6초 크로스페이드 슬라이드. 캡션 `{앨범명} — D-N` 자동.
  폴백: 세로 없음→중앙 크롭 1장 → 컨셉 포토 없음→커버 → 멤버 사진.
  모바일 히어로는 타이포 중심(사진 없음).

## 멤버 (2026-07-11 확정)
- **PC 목록**: 균등 3열×2줄 풀블리드 그리드(모든 칸 동일 크기),
  6번째 빈 칸은 연한 `fromis_9` 워드마크로 마감. 전 멤버 섹션 없음.
  헤더: `MEMBERS` 대형 타이포(BERS 그린 아웃라인) + `5 MEMBERS · SINCE 2018. 01. 24`
- **모바일 목록**: 에디토리얼 리스트(넘버링+원형 사진+영문명+생일)
- **상세 (신설)**: 잡지 프로필 스프레드 — 좌 대형 사진 / 우 이름 타이포 +
  팩트 시트(생일·SNS만 — 별명/데뷔 제외), 다음 생일 D-day 카드,
  RECENT PHOTOS(멤버 태깅 컨셉 포토 자동 수집, album_photo_members 활용)
- 파일: M_final_list_pc / M_final_list_mobile / M_final_detail_pc / M_final_detail_mobile

## 앨범 (2026-07-11 확정)
- **목록**: 연도 타임라인 구조 — `{연도} ──── N RELEASES` 헤어라인 아래
  커버 그리드(PC 4열/모바일 2열). 카드: 커버 위 통산 번호, 상단 굵은 룰 +
  제목·타입, 타이틀곡(그린)·발매일·곡수. 커버 없으면 placeholder
- **상세**: PC 스프레드(좌 연회색 지면+커버 그림자 / 우 타입 키커+제목+
  팩트 시트[발매일·타이틀곡·곡수/총시간]+MV·소개 버튼),
  TRACKLIST 에디토리얼 표(번호·TITLE 그린 태그·MV/LYRICS 유무·시간),
  CONCEPT PHOTOS 미리보기 4장+`+N VIEW ALL` 셀(헤더 링크 없음 — 중복 제거)
- 파일: A_final_list_pc / A_final_list_mobile / A_final_detail_pc / A_final_detail_mobile

## 앨범 갤러리·트랙 상세 (2026-07-11 확정)
- **갤러리**: PC는 행 높이 통일 justified(width/height로 행 계산),
  모바일은 기존과 동일한 2열 컬럼. 사진 캡션(번호—컨셉), 상단 필터 바
  (컨셉 버전·단체/개인/유닛 — concept_name/photo_type 활용)
- **트랙 상세**: 히어로에 TITLE 그린 태그+곡명 대형 타이포+아웃라인
  트랙 번호 워터마크. PC 우측 MV 카드, 크레딧 팩트 시트,
  가사/IN THIS ALBUM(현재 곡 하이라이트) 2단 — 모바일은 세로 흐름
- 파일: A_final_gallery_pc / A_final_gallery_mobile / A_final_track_pc / A_final_track_mobile

## 일정 메인·데이트픽커 (2026-07-11 확정)
- **PC**: 달력+선택일 리스트 상시 스프레드. 좌 월 달력(헤어라인 셀·
  카테고리 점·오늘 그린 테두리·선택일 잉크 블록) / 우 날짜 헤더+리스트.
  헤더 년월 클릭 → YEAR/MONTH 팝오버(범위 밖 비활성)
- **모바일**: 가로 날짜 스트립+필터 칩+리스트(현행 구조 + C 토큰).
  달력 펼침(오늘 버튼 그린 캡슐), 년월 피커는 YEAR/MONTH 그리드 전환
- **카테고리 라벨은 한글**(데이터 그대로 — 영문명 없음), 색 점+텍스트
- 날짜 미정: 점선 구분선 + `--:--`
- 파일: S_final_main_* / S_final_picker_*

## 일정 상세 — 유튜브·X (2026-07-11 확정)
- **유튜브 롱폼**: 세로 흐름 — 16:9 플레이어(PC 중앙 1000px) → 제목 →
  채널 행(채널명+버튼만, 아바타/YouTube 라벨 없음) → 멤버 팩트
- **유튜브 숏츠(PC)**: 가로 2단 — 9:16 프레임(배경 없음) + 정보(560px),
  두 블록 중앙 정렬로 간격 축소. 크럼에 `유튜브 · SHORTS`
- **X**: 게시물 헤어라인 카드(프로필·본문 해시태그 그린·이미지 그리드·
  시각·잉크 'X에서 보기' 버튼). 이미지 3장 = 좌 세로 2칸 + 우 2장(현행
  배열), 멤버 표시 없음. PC는 중앙 760px 단일 카드
- 파일: D_final_youtube_* / D_final_x_*

## 콘서트·특수 카드·검색 (2026-07-11 확정)
- **콘서트**: 회차 탭(현재=잉크 블록), 좌 포스터/우 정보(장소·지도),
  하단 SETLIST(번호 리스트+펼치기)/MD 2단. 모바일은 세로 흐름
- **생일/데뷔 카드**: 파스텔 지면+헤어라인 보더 에디토리얼 카드 —
  생일(연핑크·HAPPY {NAME} DAY·멤버 원형·🎂), 주년(연그린·N YEARS 원형 배지·✦)
- **검색**: PC 대형 입력(40px/굵은 언더라인)+RECENT 칩+4열 결과 표
  (매치 그린 하이라이트), 모바일 컴팩트 동일 구조
- **팬사인회 보류**(현 사이트에도 없음), **기본형 상세 제외**
- 파일: D_final_concert_* / D_final_special_cards / S_final_search_*
